# 5. Decisions

## D-001: Agent docs follow the AgentsTemplate layout (2026-11-02)

- **Context:** coding agents need the same instructions every session, in every repository of a workspace, and in
  every feature of a repository. Claude Code is the agent we target; others may follow.
- **Decision:** AGENTS.md holds only the rules every turn needs and imports the two docs every session needs, the
  project index (`1.<PROJECT>.md`) and the instructions; CLAUDE.md only imports AGENTS.md. The project index is the
  one index, and the numbered docs each hold one kind of content and never name each other. A feature mirrors this
  one level down: its index, `1.<FEATURE>.md`, is built like the project's, so a feature can become a project of its
  own. How to change any of these docs is the agent-docs skill, not the docs. Rules start with Always, Ask first or
  Never. Features don't nest. Source: [AgentsTemplate](https://github.com/SoraTehk/AgentsTemplate).
- **Rejected:** one long CLAUDE.md (it costs context every turn, and another agent couldn't share it); the index in
  AGENTS.md (a feature's index couldn't mirror it); editing rules in each doc (every session paid for them, though
  only edits need them); a work repository per feature (it splits one build and one session across agents).
- **Revisit when:** a feature needs its own build or release cycle: make that feature a work repository.

## D-002: Engine commands run through Tools/python.cmd (2026-11-02)

- **Context:** a command should run as written on any machine, and an approval a developer saves should match it.
- **Decision:** every engine command is a subcommand of `Tools/ue.py`, run as `Tools/python.cmd Tools/ue.py <command>`.
  `python.cmd` finds the engine's Python from the `.uproject`'s `EngineAssociation` in the registry, as Unreal's own
  tools do (or `UE_ENGINE_DIR`, when set), and `ue.py` finds the `.uproject` and the editor target itself. Commands
  prompt as usual; each developer's "don't ask again" approvals are their own.
- **Rejected:** commands that start `& "$env:UE_ENGINE_DIR\..."` (Claude Code can't save an approval for a program
  named by a variable); a per-machine engine variable (it drifts from what Unreal Build Tool and Rider use); a
  PreToolUse hook approving the commands the instructions list (a second mechanism, 0.3 s on every command, for prompts
  that are acceptable); `permissions.allow` rules (a second list that drifts from the instructions); Python from
  `PATH` (another prerequisite).
- **Revisit when:** prompts for the instructions' own commands get in the way, or a run with no user needs them.
