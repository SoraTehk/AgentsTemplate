# 4. Test

## Framework

| Kind | Framework | Lives in | Named |
| --- | --- | --- | --- |
| Logic, one module | Automation Spec: `BEGIN_DEFINE_SPEC` / `END_DEFINE_SPEC`, with `Describe` and `It` | `Source/{{MODULE_NAME}}/Tests/<Feature>/<Subject>Spec.cpp` | Spec `{{PROJECT_NAME}}.<Feature>.<Subject>`; each `It` states one behaviour |

**Ask first** before changing the framework, where tests live or how they're named.

## Writing a test

- **Always** wrap each test file in `#if WITH_AUTOMATION_TESTS`, so shipping builds leave it out.
- **Always** use the test flags the engine's own specs use in its version.
- **Always** have a test set up what it needs and destroy it. **Never** depend on another test or on the order they
  run in.
- **Never** use real time, randomness or the network: inject them.
